    Privacy & security

    Your stream stays
    between your computers.

    Every frame and every sound is encrypted before it leaves your gaming PC, and only a computer you've paired can read it. Unpaired computers can never send anything.

    Noise_XX_25519_ChaChaPoly_BLAKE2s

    Encrypted, every frame.

    Every connection runs a Noise XX handshake with Curve25519 keys, then seals each frame with ChaCha20‑Poly1305. The same suite Crispy uses.

    Pairing that can't be guessed.

    SPAKE2 over ristretto255 checks the six‑digit code inside the encrypted session, so an attacker gets one guess per try. Compare fingerprints to be extra sure.

    Keys stay home.

    Your identity key is sealed with Windows Data Protection, or kept private to your user account on Mac. The feed to OBS never leaves the computer it runs on.

    Your computer may ask you to confirm before opening Trick for the first time. That's normal for apps downloaded from the web. Here's what to do. Downloads are served from GitHub Releases.

    Setup

    Live in a few minutes.

    1. 1

      Open the disk image.

      Double-click Trick_1.0.0_universal.dmg, then drag Trick into your Applications folder.

    2. 2

      Open Trick.

      If macOS says it can't verify the app, go to System Settings › Privacy & Security and click Open Anyway.

    3. 3

      Allow screen & sound.

      The first time you go live, macOS asks to let Trick record your screen and system audio, and to find computers on your local network. Say yes to both.

    4. 4

      Pair and go live.

      Click Add computer, pick your other computer, and type the six digits it shows. Then hit Go live.

    1. 1

      Run the installer.

      Double-click Trick_1.0.0_x64-setup.exe and follow the steps.

    2. 2

      Get past SmartScreen.

      If you see “Windows protected your PC,” click More info, then Run anyway.

    3. 3

      Allow through the firewall.

      If your computers can't see each other, allow Trick on private networks — or click Allow Trick through the firewall in Trick's settings.

    4. 4

      Pair and go live.

      Click Add computer, pick your other computer, and type the six digits it shows. Then hit Go live.

    Then connect OBS on your streaming PC.

    In OBS, open Tools › WebSocket Server Settings and turn on Enable WebSocket server. Then, in Trick, open OBS and click Set up OBS. Prefer doing it by hand? Add a Media Source pointed at http://127.0.0.1:24790/live.
